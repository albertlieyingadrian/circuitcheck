---
title: "Command line"
description: "circuitcheck diff, summarize, validate, label and version."
---

```bash
circuitcheck --help
```

| Command | What it does |
|---|---|
| `circuitcheck summarize GRAPHS... --group NAME --out FILE` | Turn `.pt` or Neuronpedia graph files into a summary group (appends to FILE) |
| `circuitcheck diff FILE --before G --after G [--control-before G --control-after G] [--replication-before G --replication-after G] [--top-k 10] [--min-present 6] [--html P] [--json P]` | Diff two groups |
| `circuitcheck validate --demo` or `--model M --transcoders T --prompt P --features L:F@POS,... --target T --contrast C [--counterfactual P]` | Validate features |
| `circuitcheck label --neuronpedia MODEL/SOURCE --features I,J` or `--records FILE` `[--provider anthropic\|openai] [--model M] [--score detection\|simulation\|both\|none] [--compare] [--export P]` | Label features |
| `circuitcheck version` | Print the version |

Every command that produces a report takes `--html` and `--json`.

```bash
circuitcheck validate --demo --json validate.json
```
